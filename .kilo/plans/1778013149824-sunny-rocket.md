# Plan: Corrección de Extract HTML, Caché y Truncado de Títulos en Portfolio

## Problemas

### Problema 1: Extract con HTML codificado
Los extract (descripciones) de las cards muestran **etiquetas HTML codificadas** (`&lt;p&gt;...`) en lugar de texto plano.

### Problema 2: Caché inválido
El caché (`sessionStorage`) almacena datos con el extract sin limpiar, por lo que al desplegar nueva versión se sigue mostrando HTML.

### Problema 3: Títulos desbordados en cards
El título del proyecto (`.text-main` dentro de `h2`) puede ser muy largo y:
- Romperse en múltiples líneas (no se quiere)
- Salirse del ancho de la card
- No muestra indicador de truncado (ellipsis `...`)

**Requisitos:**
- `.text-main` debe mostrar **máximo 2 palabras**.
- El `h2` completo debe mantener el ancho de la card (sin saltos de línea).
- El texto truncado debe verse con `text-overflow: ellipsis`.

## Causa raíz

### Extract HTML
- `node.excerpt` de WordPress incluye etiquetas HTML (`<p>...</p>`).
- Se asignaba directamente: `extract: node.excerpt || stripHtml(node.title)`
- Al inyectar con `innerHTML` y escapar después, se visualiza como entidades codificadas.

### Caché
- Clave antigua: `portfolio_cache_v1`. Al cambiar el procesamiento, datos viejos persisten.

### Títulos
- Actualmente: `h2` containiene texto directo sin estructura `.text-main`.
- CSS no aplica `white-space: nowrap` ni `text-overflow: ellipsis` al título.
- Flex column en `.project-title` permite que el `h2` crezca y se envuelva.

## Solución

### 1. Sanitización del extract (como en plan original)
- Aplicar `stripHtml()` a `node.excerpt`.
- Actualizar `CACHE_KEY` a `portfolio_cache_v2` para invalidar caché.

### 2. Truncado de títulos

#### Cambios en `portfolio-grid.js` (createCardTemplate):

**Estructura HTML actual:**
```html
<h2>${escapeHtml(card.title[0])} <small>| ${escapeHtml(card.title[1])}</small></h2>
```

**Nueva estructura:**
```html
<h2>
  <div class="text-main" title="${escapeHtml(card.title[0])}">${escapeHtml(truncateToWords(card.title[0], 2))}</div>
  <small>| ${escapeHtml(card.title[1])}</small>
</h2>
```

**Función `truncateToWords(text, maxWords)`:**
```javascript
function truncateToWords(text, maxWords) {
  if (!text) return "";
  const words = text.split(/\s+/).filter(w => w);
  if (words.length <= maxWords) return text;
  return words.slice(0, maxWords).join(" ") + "...";
}
```

#### Cambios en CSS (`index.html` → estilos de `.card`):

```css
/* Contenedor del título: ahora row en lugar de column para mantener una línea */
.card > section .project-header .project-title {
  display: flex;
  flex-direction: row; /* Cambio: de column a row */
  align-items: baseline;
  gap: 0.5rem;
  width: 100%;
  min-width: 0; /* Permite que los hijos se encojan */
}

/* h2: no-wrap, ellipsis */
.card > section .project-header .project-title h2 {
  margin: 0;
  margin-block-end: 0.5rem;
  font-size: 1.25rem;
  color: var(--title-color);
  display: flex;
  align-items: baseline;
  gap: 0.35rem;
  width: 100%;
  min-width: 0;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* .text-main: truncado con ellipsis */
.card > section .project-header .project-title .text-main {
  display: block;
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
  min-width: 0; /* Permite shrink en flex */
  font-weight: 600;
  line-height: 1.2;
}

/* small: no se trunca, se mantiene visible */
.card > section .project-header .project-title h2 small {
  font-size: 0.8em;
  opacity: 0.8;
  flex-shrink: 0; /* Evita que el small se encoja */
  white-space: nowrap;
}

/* Span de categorías: debajo del h2 */
.card > section .project-header .project-title span {
  font-size: 0.85rem;
  color: var(--text-color);
  opacity: 0.7;
  /* Se mantiene debajo, en flex column original, pero ahora con row en h2 */
}
```

**Nota:** Al cambiar `flex-direction: column` a `row` en `.project-title`, el `span` de categorías bajará automáticamente a la siguiente línea porque el `h2` ocupará el ancho completo. Esto mantiene el diseño: título en una línea, categorías abajo.

### 3. Atributo `title` para tooltip
Se agrega `title="${escapeHtml(card.title[0])}"` en `.text-main` para que al hover se vea el texto completo.

## Verificación

1. **Extract:** Las cards muestran texto plano sin `&lt;p&gt;`.
2. **Títulos:** 
   - "Punta Medano • Los Cabos" → se trunca a "Punta Medano..." si supera el ancho.
   - El separador `| Restaurant Brand` permanece visible.
   - Al hacer hover sobre el título truncado, aparece tooltip con texto completo.
3. **Layout:** El `h2` no ocupa más de 1 línea; las categorías (`span`) se muestran en línea aparte debajo.
4. **Responsive:** En cards estrechas, el truncado se aplica correctamente.
5. **Caché:** Al recargar, los datos se obtienen frescos (clave v2).

## Riesgos

- Si `truncateToWords` se ejecuta en texto ya truncado (ej. desde API), podría añadir `...` duplicados. Se mitigar aplicando solo si `!text.endsWith("...")`.
- Cambio de `flex-direction` en `.project-title` podría afectar alineación vertical. Se prueba con `align-items: baseline`.
- Clase `.text-main` podría no ser necesaria si se aplica directamente a `h2 > :first-child`. Se usa div para mayor control.

## Alternativas consideradas

- **Line-clamp:** `display: -webkit-box; -webkit-line-clamp: 2;` → No, porque se requiere **1 línea** (no 2).
- **Max-width + JS:** Más preciso pero más complejo. Se opta por CSS puro con `text-overflow: ellipsis`.
